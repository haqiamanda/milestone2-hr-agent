# Architecture Assignment

Gunakan `templates/architecture.md` untuk menggambar rancangan Anda sendiri sebelum implementasi. Diagram final wajib menunjukkan data flow, identity boundary, RAG indexing/query paths, agent/tool loop, confirmation transaction, telemetry/redaction, Redis degradation, evaluation runner, dan human review.

Setiap tim harus menjelaskan keputusan dan trade-off-nya sendiri.
